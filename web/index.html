Five Room Dungeon Generator

Procedurally generates a dungeon made of interconnected five-node modules, based on The Twenty-one Forms Of The Five Room Dungeon and Steve Lawford's "Counting five-node subgraphs".
This uses Pyodide to run the command-line toolool in the browser.

Loading Python runtime… this can take a few seconds.
